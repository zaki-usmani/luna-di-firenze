# Luna di Firenze 🇮🇹☕

A multi-page website for a fictional Italian café, built from scratch with HTML and CSS to practise front-end fundamentals and web design.

> This is my first full web development project — built as part of my journey learning front-end development.

---

## 📖 About the Project

**Luna di Firenze** ("Moon of Florence") is a fictional café inspired by the charm and café culture of Florence, Italy. The site imagines a small, elegant café with a warm, earthy Italian aesthetic — think terracotta, olive green, and cream tones.

The project is built as a multi-page site rather than a single landing page, so it covers real-world structure: a homepage, a full menu, an about page, and a contact page, all sharing consistent navigation and styling.

## ✨ Features

- 🏠 **Homepage** — hero banner with call-to-action, Florence-inspired imagery
- 📋 **Menu page** — categorised sections (Beverages, Pasta, Pizza, Desserts) with images, descriptions, and prices, laid out in a responsive wrapping grid
- ℹ️ **About Us page** — café story and interior photos
- 📞 **Contact page** — café details
- 🧭 Navigation bar
- 🎨 Custom Italian-inspired colour palette
- 🖼️ Custom favicon
- 🧱 Clean, semantic HTML structure throughout

## 🛠️ Built With

- **HTML5** — semantic markup
- **CSS3** — Flexbox-based layouts, custom fonts, responsive wrapping grids

No frameworks, build tools, or JavaScript — this project is deliberately kept to core HTML/CSS to focus on layout and styling fundamentals.

## 🚀 Getting Started

Since this is a static HTML/CSS site with no dependencies, you can run it locally in one step:

1. Clone the repo
   ```bash
   git clone https://github.com/zaki-usmani/luna-di-firenze.git
   ```
2. Open `index.html` in your browser (or use an extension like VS Code's *Live Server* for auto-reloading while you edit)

No build step, no `npm install` — just open and go.
